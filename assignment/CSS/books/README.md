📚 Modern Book Store Landing Page
An elegant and responsive bookstore interface designed for high readability and a welcoming user experience. This project demonstrates advanced CSS techniques, including custom gradients and flexbox layouts.

📌 Project Overview
This bookstore frontend features a minimalist navigation system, an inspiring hero section with a call-to-action, and a flexible grid for displaying featured titles. It is optimized for speed and visual clarity.

✨ Key Features
Modern Navigation: Includes a logo and a stylized rounded search bar for a professional feel.

Warm Hero Section: A vibrant linear gradient (#ff9a44 to #fc6076) designed to draw immediate attention.

Interactive Book Grid: Uses flex-wrap and justify-content to ensure books align perfectly on different screen sizes.

Hover Animations: Subtle Y-axis transitions on book covers to increase user engagement.

Refined Typography: Utilizes the Segoe UI font stack for a native-app feel.

🛠️ Technical Stack
HTML5: Semantic structure with <header>, <main>, and <section> tags.

CSS3: * Gradients: Used 135-degree linear gradients for a sophisticated depth.

Flexbox: Implemented for both the navigation bar and the book display grid.

Transitions: Smooth hardware-accelerated transforms on interactive elements.
