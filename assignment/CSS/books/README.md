# 📚 Modern Online Book Store UI

A vibrant and responsive landing page for a digital bookstore. This project focuses on product presentation, featuring a dynamic book grid, a searchable navigation bar, and a high-conversion hero section.

## ✨ Features
* **Hero Section:** Eye-catching linear gradient (`#ff9a44` to `#fc6076`) with a call-to-action button.
* **Flexbox Book Grid:** A responsive display of featured titles that automatically wraps based on screen size.
* **Hover Interactions:** Smooth scale and translation effects on book covers to improve user engagement.
* **Search Integration:** A stylized search bar in the navigation for quick product discovery.
* **Clean Typography:** Professional sans-serif font stack for a modern reading experience.

## 🛠️ Built With
* **HTML5:** Semantic structure including `header`, `main`, and `section` tags.
* **CSS3:** Custom styling with:
    * **Flexbox:** For the navbar and book grid alignment.
    * **Transitions:** For smooth interactive hover states.
    * **Gradients:** For the modern hero background.
