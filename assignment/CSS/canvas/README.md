♾️ Infinity Love - Creative Canvas AnimationAn interactive, math-driven animation built using the HTML5 Canvas API. This project visualizes the infinity symbol through trigonometric functions and glowing particle effects.📌 Project Overview"Infinity Love" is an experimental UI piece that combines a minimalist landing state with a dynamic animation. Upon user interaction, the script calculates a custom parametric path to draw a continuous infinity loop using a trailing glow effect.✨ Key FeaturesTrigonometric Animation: Uses Math.cos(t) and Math.sin(t * 2) to programmatically plot a figure-eight (infinity) path.Interactive Trigger: Features a "Tap to Start" entry point that transitions the UI into the animation state.Visual Trail Effect: Implements a "ghosting" technique by filling the canvas with a low-opacity rectangle (rgba(5, 5, 5, 0.05)) on every frame instead of clearing it.Glow & Shadow Engine: Utilizes shadowBlur and shadowColor properties to create a neon-like aesthetic.Responsive Layout: Includes a window resize listener to ensure the animation remains centered on any screen size.🛠️ Technical ImplementationLanguage: HTML5, CSS3, JavaScript.Core API: CanvasRenderingContext2D & requestAnimationFrame.Mathematical Logic:X-coordinate: $x = \text{center} + \cos(t) \times \text{radius}$Y-coordinate: $y = \text{center} + \sin(t \times 2) \times \text{radius}$Styling: CSS Flexbox for centering and modern transitions for the interactive button.📂 Project StructurePlaintext├── index.html       # Combined file containing Logic, Style, and Structure
