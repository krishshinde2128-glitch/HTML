# 🏄 WaveRiders Surf Academy - Landing Page

A high-impact, responsive landing page designed for a surfing school. This project combines vibrant visual storytelling with a clean, functional layout to drive user engagement and course enrollments.

## ✨ Features
* **Sticky Navigation:** A user-friendly navigation bar that stays fixed at the top for easy access to different sections.
* **Hero Experience:** A bold header featuring a gradient-overlay background image and a prominent "Join Now" call-to-action.
* **Course Catalog:** A multi-tier course display (Beginner, Intermediate, Pro) using specialized cards with clean typography and image containment.
* **Modern CSS Architecture:** Utilizes **CSS Variables** (`:root`) for global theme management, making the primary and secondary colors easily swappable.
* **Responsive Layout:** Built with a "mobile-first" mindset using **Flexbox**, ensuring the gallery and course cards stack beautifully on smaller screens.

## 🛠️ Built With
* **HTML5:** Semantic elements like `nav`, `section`, and `footer` for optimal structure and SEO.
* **CSS3:** Advanced styling techniques including:
    * **Linear Gradients:** Used for image overlays to maintain text legibility.
    * **Transitions & Transforms:** Interactive button effects for better user feedback.
    * **Object-Fit:** Ensuring gallery and course images maintain their aspect ratio across various sizes.
