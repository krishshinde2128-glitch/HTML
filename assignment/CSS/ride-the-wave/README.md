🏄 WaveRiders Surf Academy Landing Page
A vibrant, responsive landing page for a fictional surf school. This project focuses on clean UI design, modular CSS using variables, and a mobile-friendly flexible layout.

📌 Project Overview
WaveRiders is designed to capture the energy of extreme sports through a bold color palette and clear call-to-action elements. It features a sticky navigation system and a structured course showcase.

✨ Key Features
Sticky Navigation: A user-friendly header that stays at the top of the viewport during scrolling.

Hero Section: High-impact entrance with a dimmed background image and centered typography to ensure readability.

Course Catalog: A flexible grid of cards showcasing different skill levels (Beginner to Pro).

Interactive UI: Hover effects on buttons using CSS transforms for a more "tactile" user experience.

Modular Styling: Utilization of CSS :root variables for easy theme management (Colors, Spacing, Border Radius).

🛠️ Tech Stack
HTML5: Structured with semantic elements for better SEO.

CSS3: * Flexbox: Used for the navigation bar and the responsive course grid.

CSS Variables: Centralized color and spacing management.

Box Model: Strategic use of padding, margins, and box-shadow for card depth.
