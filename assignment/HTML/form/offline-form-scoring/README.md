# 🌙 Luna Deep - Minimalist Form UI

A visually striking, dark-themed input form featuring a custom "Luna" color architecture. This project focuses on high-contrast accessibility, smooth transitions, and a futuristic aesthetic using modern CSS techniques.

## ✨ Features
* **Custom Color System:** Utilizes a carefully curated `:root` variable set ranging from `luna-ice` to `luna-midnight`.
* **Atmospheric Background:** Implements a `radial-gradient` that simulates a deep-space or midnight-ocean horizon.
* **Frosted Glass Effect:** The form container uses semi-transparent backgrounds and subtle borders for a modern, layered look.
* **Interactive Inputs:** Custom focus states with glowing borders and smooth `translateY` hover animations on the submit button.
* **Responsive Styling:** Uses `box-sizing: border-box` to ensure consistent padding and layout integrity across devices.

## 🛠️ Built With
* **HTML5:** Semantic form structure and specialized input types (`email`, `number`).
* **CSS3:** Advanced styling including:
    * **CSS Variables:** For maintainable theme tokens.
    * **Flexbox:** To perfectly center the UI in the viewport.
    * **Transitions:** For smooth state changes (0.3s ease).
